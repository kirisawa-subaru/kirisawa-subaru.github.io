8. [proved] 解递推：得到 \(1/\sqrt{\ln K}\)
定义
\[
q_0=2^{48},\qquad
q_{j+1}=\bigl(q_js(q_j)\bigr)^2,
\qquad
x_j=\ln q_j.
\]
那么
\[
x_{j+1}=2x_j+2\ln s(q_j).
\]
由于附加项只有 \(O(\ln x_j)\)，可以沿用上一轮的显式估计
\[
x_0\,2^j\le x_j\le A_0\,2^j,
\tag{31}
\]
其中
\[
A_0=x_0+6\ln x_0+6\ln3+2\ln65
=69.2396\ldots.
\]
乘法误差也不会改变主幂次。令 \(\rho=1/\sqrt2\)，则
\[
\begin{aligned}
\prod_{i<j}\left(\rho+\frac2{x_i}\right)
&\le
\rho^j
\exp\left(\frac2\rho\sum_{i<j}\frac1{x_i}\right)\\
&\le
\rho^j\exp\left(\frac4{\rho x_0}\right).
\end{aligned}
\tag{32}
\]
而 \(1/q_j=e^{-x_j}\) 衰减得更快。由 \(e(q_0)<1/2\)，
\[
\boxed{
e(q_j)
\le
\frac12
\exp\left(\frac4{\rho x_0}\right)2^{-j/2}.
}
\tag{33}
\]
结合 \(x_j=\Theta(2^j)\)，
\[
e(q_j)=O(x_j^{-1/2})
=O\!\left(\frac1{\sqrt{\ln q_j}}\right).
\]
推广到全部规模，使用普通分块给出的界
\[
e(N)\le4\max\{k^{-1},e(k)\},
\qquad 2\le k\le N.
\]
选最大的 \(q_j\le N\)。由于
\[
\ln N<\ln q_{j+1}\le3\ln q_j,
\]
得到
\[
\boxed{
e(N)=O\!\left(\frac1{\sqrt{\ln N}}\right).
}
\tag{34}
\]
保留上述粗常数，全部规模上的系数至多
\[
4\cdot\frac12
\exp\left(\frac4{\rho x_0}\right)
\sqrt{3A_0}
=34.1671\ldots.
\]
所以可以写成方便核查的显式界
\[
\boxed{
e(K)\le\frac{36}{\sqrt{\ln K}},
\qquad K\ge2.
}
\tag{35}
\]
这个常数没有优化；实质改进是衰减幂次。
这次的机制可以压缩成一句话：四条外腿产生一个 \(4n\) 的总次数预算，两个切分分别消耗 \(k\) 和 \(4n-k\)；分拆数按 \(\exp(c\sqrt n)\) 增长，于是最坏的平衡分配把原来的对数秩预算 \(4\lambda\) 压成 \(2\sqrt2\,\lambda\)。

最终的两个关键界是：
\[
\boxed{
\begin{gathered}
\text{[proved]}\quad
S_{2^\lambda}
=\sum_{k=0}^{4n}T_k,\qquad n=O(\lambda^2),\\
r_{\mathrm{上下}}(T_k)r_{\mathrm{左右}}(T_k)
\le
2^{\,2\sqrt2\,\lambda+O(\sqrt\lambda+\ln\lambda)},\\[2mm]
\text{[proved，接入前述全局递推]}\quad
e\bigl(q^2\lceil64(\ln q)^3\rceil^2\bigr)
\le
\max\left\{
q^{-1},
\left(2^{-1/2}+\frac2{\ln q}\right)e(q)
\right\},\\[2mm]
e(K)\le\frac{36}{\sqrt{\ln K}}.
\end{gathered}
}
\]
因此，多项式环算子加分拆数估计不是给旧方法补一个常数优化，而是提供了一套更强的局部分解，正好把递推的衰减指数推到 \(1/2\)。
